===== 正文开始 =====

Deadlock（异锁）现在中文玩家不少，但聊天框里还是经常蹦出一串英文：队友喊 push、mid no、gg，
看得懂还好，看不懂就只能干瞪眼。

分享一个我自己在用的免费小工具：**通译**。它做的事很简单 —— 让聊天框里的英文变成中文，
让你打的中文变成英文发出去。

【一】它到底干嘛的

就两件事：

· 看：队友、对手在聊天框里打的英文（俄语也认），你这边直接显示中文，原文也留着，想看能看。
· 说：你在聊天框里打中文，连按两下空格，它就变成"中文 | 英文"，回车发出去。

装完之后聊天还是原来那个聊天，只是你终于看得懂了。

【二】它是怎么做到的

工具分两部分，两个都要装：

· 汉化补丁（游戏内 mod）：负责把中文画在聊天框里。
· 翻译器（电脑后台小程序）：负责把英文翻成中文。

补丁是在游戏自己的聊天界面里读写文字，所以：不读游戏内存、不注入 DLL、不改游戏文件、
不模拟按键，也不会动游戏本体。翻译请求只发给你自己电脑上的 localhost:8791。

【三】下载

GitHub 下载页（认准文件名 tongyi-players.zip，约 32 MB，不需要装 Python）：

https://github.com/17601413731/deadlock-tongyi/releases/latest

打不开 GitHub 的话看文末的备用地址。

【四】安装（4 步，只需要做一次）

第 1 步 解压
解压到一个普通文件夹就行（别放 Program Files，那里没有写权限）。

第 2 步 装翻译器
双击 tongyi_launch\START_HERE.bat。
它会自动生成一行启动配置并复制到剪贴板，你只要：
Steam → 库 → 右键 Deadlock → 属性 → 启动选项 → Ctrl+V 粘贴。
只配这一次。以后照常点"开始游戏"，翻译器跟着游戏一起开、退游戏自动关。
（挪过文件夹位置的话，要重新双击一次再粘。）

第 3 步 装汉化补丁
先下载 Deadlock Mod Manager（DMM，社区通用的 mod 管理器）：https://deadlockmods.app
打开 → My Mods → 添加本地 mod → 选中压缩包里的 mod\tongyi-pak01_dir.vpk 文件 → 起个名字（比如"通译"）→ 在「我的模组」里启用。

第 4 步 填一次翻译用的 Key
先开一次游戏，然后浏览器打开：

http://localhost:8791/settings

把你自己的 DeepSeek Key 粘进去保存（注册地址 https://platform.deepseek.com）。
Key 只存在你自己电脑上，不会发给别人，也不在这个压缩包里。

注意这一步要在游戏开着的时候做 —— 翻译器跟游戏同一条命，平时那个端口是不开的。

【五】怎么用

· 看：什么都不用按，英文聊天自己变中文。
· 说：打完中文 → 连按两下空格 → 输入框变成中英对照 → 回车。
· 设置：聊天框里输入 /tongyi 按回车，打开设置面板。
  （面板要用鼠标点，而游戏里平时没有鼠标指针，先按一下 Tab 把鼠标调出来再点。）

面板里能调：中文是拼在英文后面还是只显示中文、自己发的消息是"中英都发"还是"只发英文"、
触发键是两下还是三下空格、要不要保护英雄和物品名（术语表，避免 mid no 翻成"中间不"这种）、
以及翻译走云端还是走你自己电脑。

【六】怎么知道装好了

进游戏看聊天输入框右边的小圆点：

· 绿色 = 一切正常
· 灰色 / 红色 = 翻译器没连上

没连上多半是启动选项粘错了（路径或引号），重新双击一次 START_HERE.bat 再粘一遍就行。
还不行的话看日志：%APPDATA%\deadlock-tongyi\logs\launcher.log

【七】几个常见问题

· 要花钱吗？
  工具本身免费、开源的。翻译用的是你自己的 DeepSeek Key，按量计费 —— 纯聊天文字量很小，
  费用很低。不想花钱或者不想让聊天内容出网，可以在设置面板里切成"本机 Ollama"，
  完全在你电脑上跑，一句都不外传（前提是电脑跑得动小模型）。

· 聊天内容会外传吗？
  默认走云端翻译，聊天内容会发给你自己的 DeepSeek 账号；切成"本机 Ollama"之后就完全不出本机。

· 会拖慢游戏、占显卡吗？
  不会。翻译器只在游戏运行时存在，空闲时几乎不占 CPU，翻译在云端做，不占显卡。

· 杀毒软件报了怎么办？
  打包出来的小程序偶尔会被误报，加个信任就行。它不改游戏文件、不注入进程，只发本机网络请求。

· 能和别的翻译 mod 一起用吗？
  不能。它和 BabelTower 都替换聊天界面的文件，只能留一个。

· 怎么卸载？
  ① 清空 Steam 启动选项 ② 删掉解压出来的文件夹 ③ 在 DMM 里删掉这个 mod
  ④ 想清干净再删 %APPDATA%\deadlock-tongyi\
